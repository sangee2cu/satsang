# Satsang website

A responsive single-page Satsang website with Home and Navaratri Golu/RSVP tabs.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. After GitHub Pages finishes building, the site should be available at https://sangee2cu.github.io/satsang/.

## RSVP email setup
The RSVP form uses FormSubmit to forward submissions to sangee2cu@gmail.com. On the first test submission, check that inbox for a FormSubmit activation email and confirm it. Test the form after activation.

## Before sharing
Confirm the invitation days and hours are correct. The current invitation lists Friday and Sunday, 6–9 PM.
